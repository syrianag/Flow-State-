Flowstate is a burnout-aware planning system built to solve a common problem: my schedule lies because I can’t accurately estimate time and energy—so I overcommit, procrastinate, and my work quality drops when I’m tired.

Flowstate helps by combining simple rules with supportive guidance:

Daily Check-in (minutes + energy + stress): calculates a realistic capacity for the day.
Capacity Gate: prevents planning more work than your plan budget (capacity minus buffer).
Recovery Mode: automatically reduces workload expectations on low-energy / high-stress days.
Next Action Enforcement: tasks can’t be scheduled unless they have a clear next action (prevents vague “work on it” tasks).
Focus Blocks tied to Tasks: start a timed focus session and log real time spent to keep planning honest.
AI Task Shaper: generates next actions, an estimate, energy cost, a Definition of Done, and a minimum viable version so tasks become schedulable and easier to start.
Tech Stack: Next.js (App Router), React 19, Tailwind CSS, Prisma, SQLite (dev).

Goal: Plan less, finish more, protect your energy, and complete work with consistent quality—without burning out.
